Instructions & Template Requirements:

Please ensure your Excel file (.xlsx) adheres to the following structure:

  • FECHA: Date (Format: YYYY-MM-DD)
  • TIENDA: Integer
  • SKU: Integer
  • DESCRIPCION_GDN: Text (Max 255 characters)
  • EAN: Integer (Typically 13 digits)
  • PRECIO_REGULAR_GDN: Decimal (e.g., 123.45)
  • PRECIO_OFERTA_GDN: Decimal (e.g., 100.00, optional)
  • DESCUENTO_PROMEDIO: Decimal (e.g., 0.1500 for 15%)
  • VentasQ(28d): Integer

The column headers must match exactly as listed above.
